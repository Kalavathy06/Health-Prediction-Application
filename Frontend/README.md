# Health Prediction Application

## Tech Stack

Frontend:
- React
- Tailwind CSS

Backend:
- Python Flask
- SQLite

AI Integration:
- Google Gemini API

## Features

- Create Patient
- View Patient
- Update Patient
- Delete Patient
- AI Health Prediction
- Data Validation
- Persistent Storage

## Run Backend

pip install -r requirements.txt

python app.py

## Run Frontend

npm install

npm run dev
